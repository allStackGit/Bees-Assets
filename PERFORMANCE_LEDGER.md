# Performance Ledger

Static-only audit; no runtime measurements are claimed. This ledger contains unresolved validated optimization opportunities only.

1. **PERF-031 — Pathfinder allocates priority-queue storage for every search.** `Scripts/Levels/Pathfinder.Search.cs` creates a new `IntMinHeap` and backing `List<int>` for each A* search, plus another heap for trapped-start egress. Reuse one heap per worker slot and reset its cost-array references between egress and normal search.
2. **PERF-032 — Pathfinder allocates a Stopwatch for every worker search.** `BTFindPath()` starts a new Stopwatch per request. Keep one Stopwatch per worker slot and restart it for each owned search.
3. **PERF-033 — A* recomputes adjacent movement cost through index division/modulo.** Neighbor moves are already known to be cardinal or diagonal, but the hot loop decomposes node indexes to calculate that cost and the heuristic. Use the neighbor offsets and coordinate-form octile distance directly.
4. **PERF-034 — Every completed path search allocates a PathResult wrapper.** `PathResult` is only a `ConcurrentQueue` transport envelope and has no identity/null semantics. Make the envelope a value type while retaining the owned `Path` reference.
5. **PERF-035 — Queued path dequeue uses a capturing LINQ predicate.** `ReleaseQueuedShipIfNoRemainingRequests()` scans `PathsWaiting` through `Any(request => ReferenceEquals(...))`. Scan the queue directly.
6. **PERF-036 — GameState command queries rebuild temporary collections.** `Scripts/Levels/GameState.Commands.cs/GetTargetedSquads()` allocates a new list and LINQ pipeline for GangUp selection, and `StoreCommands()` uses LINQ to repopulate an already reusable completion buffer. Clear and refill persistent buffers with direct scans.
7. **PERF-037 — Ship target reacquisition replaces pooled command queues.** `Scripts/Entities/Ships/Ship.Combat.cs/SetAndGetTargetEnemy()` still creates replacement `Queue<Ship>` objects when targeting is exhausted even though `Command` now owns reusable queue rebuild helpers. Reuse those queues; also remove non-required kill-time list snapshots and repeated side-list creation in carrier cleanup.
8. **PERF-038 — Weapon targeting cache rebuilds materialize temporary lists.** `Scripts/Entities/Ships/Weapons/Weapon.cs` allocates LINQ lists for in-range enemy selection and clones the enemy squad list when range is disregarded. Reuse weapon-owned candidate buffers while preserving cache invalidation semantics.
9. **PERF-039 — Aggressive close-range timer can run the same all-ships range predicate twice.** `Scripts/Levels/Commands/Aggressive.cs/Timer()` repeats `AreAllSquadShipsWithinRangeOfAllOfOurSquadShips()` in equivalent OR branches. Compute it once and reuse the result.
10. **PERF-040 — Healing cross visuals instantiate/destroy objects and add two Level timers per effect.** `Beehive.SpawnHealingCross()` and `HealingCross.Kill()` churn GameObjects during visible healing. A lifecycle-safe pool could remove this churn, but it must preserve Level/timer ownership and pooled Beehive teardown semantics.
