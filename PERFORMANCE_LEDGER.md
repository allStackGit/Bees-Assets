# Performance Ledger

Static-only audit; no runtime measurements are claimed. This ledger contains unresolved validated optimization opportunities only.

1. **PERF-006 — Standing-request list allocated every rendered frame.** `Scripts/Server/Socket.cs/CheckStandingRequests()` calls `StandingRequests.ToList()` unconditionally. Early-return when empty and reuse a mutation-safe snapshot list.
2. **PERF-008 — Socket response envelope parsed twice.** `SocketResponseLifecycleGuard.ShouldSuppressResponse()` and `Socket.Message()` independently decode/deserialize the same response. Parse once and pass the envelope through suppression/dispatch while preserving error ordering.
3. **PERF-014 — Mouse-edge pixel threshold projected four times per frame.** `Scripts/Levels/LevelInputManager.cs/CheckInputs()` repeats the same world-to-screen conversion; compute it once per invocation.
4. **PERF-015 — Custom-sprite pixel matching performs unnecessary square roots.** `Scripts/Utilities.cs/GetChangablePixelsForImage()` calls `Vector3.Distance()` for every color×pixel test. Compare squared RGB distance to a squared threshold and precompute source color values.
5. **PERF-020 — Full command targeting sorts recompute closest/furthest keys.** `Scripts/Levels/Commands/Command.cs/MakeTargetingQueue()` needs the full order but can cache each ship's squad-distance once before sorting.
6. **PERF-022 — ResetLevel still temporarily replaces spotted-ship containers.** `Scripts/Levels/Level.Reset.cs/ResetLevel()` assigns a reset array whose entries are cleared to null, forcing `GameState.ResetState()` to recreate the two lists even though the other GameState containers are now reused. Keep the existing lists and clear them after ship teardown instead.
7. **PERF-023 — Automated setup/reset emits unconditional formatted logs.** `Scripts/Levels/Level.Reset.cs/SetupLevel()` contains routine `Debug.Log` calls reached by repeated training setup. Gate nonessential diagnostics on automated training paths.
8. **PERF-025 — ResetLevel allocates a ship snapshot array every episode.** `Scripts/Levels/Level.Reset.cs/ResetLevel()` calls `State.GetShips().ToArray()` because killing mutates state. Reuse a dedicated snapshot list/buffer while preserving pre-kill membership.
9. **PERF-028 — Hive Mind request ban sets are rebuilt with LINQ each decision.** `Scripts/Levels/Squad.Commands.cs` recreates ship-type and command-type sets on request paths. Refill instance-owned sets without changing request-local availability semantics.
10. **PERF-029 — The capped squad ship list is rebuilt multiple times for one matchup.** `Squad.MakeMatchupAndGetCommand()` calls `GetShipsForMatchup()` repeatedly for encoding and friendly-health calculation. Build the capped snapshot once per request and reuse it.
11. **PERF-030 — Matchup encoding allocates a character array through LINQ every call.** `Squad.AddToMatchup()` selects ship letters into a new array before sorting. Reuse a bounded character buffer and sort only the populated range.
