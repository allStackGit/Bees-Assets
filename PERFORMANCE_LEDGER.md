# Performance Ledger

Static-only audit; no runtime measurements are claimed. All entries below are validated optimization opportunities and remain unresolved.

1. **PERF-001 — Per-frame timer snapshot allocation.** `Scripts/Levels/Level.Runtime.cs/UpdateTimers()` calls `Timers.ToArray()` each active frame with timers. Reuse a mutation-safe snapshot buffer.
2. **PERF-002 — Target list built before cache hit.** `Scripts/Entities/Ships/Weapons/Weapon.cs/GetPotentialEnemyTargetShips()` constructs a LINQ list before checking the existing valid targeting cache. Check the cache first.
3. **PERF-003 — Unused damage-status lookup in fallback targeting.** `Weapon.DetermineTargetShip(..., false)` still calls `GetShipDamageStatus()`. Skip that lookup when reservation state is intentionally ignored.
4. **PERF-004 — Linear ship-damage reservation lookup.** `Scripts/Levels/GameState.Queries.cs/GetShipDamageStatus()` scans a growing list on repeated combat/targeting paths. Maintain an ID-keyed index while preserving existing status object identity/list semantics.
5. **PERF-005 — Static Pathfinder grid recopied by physics frame.** `Scripts/Levels/Pathfinder.Obstacles.cs/UpdateDynamicObstacleLayer()` copies the full base-clearance grid again in static-only mode even when no dynamic obstacle changed it. Refresh only after static dirtiness or a dynamic→static transition.
6. **PERF-006 — Standing-request list allocated every rendered frame.** `Scripts/Server/Socket.cs/CheckStandingRequests()` calls `StandingRequests.ToList()` unconditionally. Early-return when empty and reuse a snapshot list.
7. **PERF-007 — Response-history pruning runs every frame.** `Scripts/Server/SocketResponseLifecycleGuard.cs/Update()` scans handled-response history every rendered frame despite a 120-second retention window. Prune on a coarse interval while preserving bounded-history behavior.
8. **PERF-008 — Socket response envelope parsed twice.** `SocketResponseLifecycleGuard.ShouldSuppressResponse()` and `Socket.Message()` independently decode/deserialize the same response. Parse once and pass the envelope through suppression/dispatch.
9. **PERF-009 — Closest/furthest weapon sorts recompute geometry keys.** `Weapon.MakeSortedTargetingList()` calls `DistanceTo()` repeatedly from sort comparators. Cache each candidate distance once per sort.
10. **PERF-010 — Rocket flare SetActive no-ops every physics tick.** `Scripts/Entities/Ships/Ship.Visuals.cs/SetRocketFlares()` repeats identical activation calls. Guard each requested state with `activeSelf`.
11. **PERF-011 — HUD layout writes the same anchored position every visible-clock frame.** `Scripts/UI Components/GameHudLayoutGuard.cs` must keep checking for legacy movement, but can skip assignment when already at the desired position.
12. **PERF-012 — Custom animation fallback rewrites the same sprite every LateUpdate.** `ShipAnimationController` and `RemainsAnimationController` should retain Animator correction but only assign when the renderer differs from `CurrentSprite`.
13. **PERF-013 — Targeting marker repeats SetActive each aim tick.** `Scripts/Entities/Ships/Weapons/Turret.Aiming.cs/MoveTargetingMarker()` can guard visibility writes with `activeSelf`.
14. **PERF-014 — Mouse-edge pixel threshold projected four times per frame.** `Scripts/Levels/LevelInputManager.cs/CheckInputs()` repeats the same world-to-screen conversion; compute it once per invocation.
15. **PERF-015 — Custom-sprite pixel matching performs unnecessary square roots.** `Scripts/Utilities.cs/GetChangablePixelsForImage()` calls `Vector3.Distance()` for every color×pixel test. Compare squared RGB distance to a squared threshold and precompute the source color values.
16. **PERF-016 — ColorPicker allocates and sorts the whole palette to find one nearest color.** `Scripts/UI Components/ColorPicker.cs/SetColor()` creates dynamic objects, computes distances, sorts them, then takes the first. Use one best-candidate scan with squared RGBA distance and stable first-tie behavior.
17. **PERF-017 — ColorPicker repeatedly resolves stable UI components.** Cache the color-square `Image`, hex `TMP_InputField`, and color-sheet `RectTransform` instead of repeated `GetComponent` calls during pointer/input work.
18. **PERF-018 — Closest squad queries sort full eligible lists.** `Scripts/Levels/Squad.Combat.cs/GetClosestEnemySquad()` and `GetClosestValidFriendlySquad()` need only one minimum. Use a single pass preserving filters and first-tie behavior.
19. **PERF-019 — Matchup strategy selection fully sorts for one winner.** `Scripts/Levels/Commands/MatchupStrategy.cs/SortSquads()` sorts for scalar min/max cases; closest/furthest also recompute distance keys and ship-type strategies recount ships inside comparators. Use single-pass extrema where tie semantics permit and precompute keys where existing `List.Sort` semantics must remain.
20. **PERF-020 — Full command targeting sorts recompute closest/furthest keys.** `Scripts/Levels/Commands/Command.cs/MakeTargetingQueue()` needs the full order but can cache each ship's squad-distance once before sorting.
21. **PERF-021 — Reset teardown allocates empty/snapshot arrays unnecessarily.** `Scripts/Levels/GameState.Registry.cs` creates `ToList`/`ToArray`/LINQ release snapshots even when corresponding runtime/release collections are empty. Add empty fast paths and reuse safe buffers where lifecycle mutation requires snapshots.
22. **PERF-022 — GameState episode reset recreates core containers.** `Scripts/Levels/GameState.cs/ResetState()` allocates new spotted lists, integer arrays, Hive Mind dictionaries, vision hash sets, and wrapper arrays each reset. Reuse/clear the existing containers while preserving the teardown phase in which spotted-state entries must not retain dead pooled ships.
23. **PERF-023 — Automated setup/reset emits unconditional formatted logs.** `Scripts/Levels/Level.Reset.cs/SetupLevel()` contains several unconditional `Debug.Log` calls reached by repeated training episode setup. Remove or gate routine diagnostics so formatting/logging is not paid on every episode.
24. **PERF-024 — Campaign trigger cleanup allocates a new list each evaluation.** `Scripts/Levels/Level.Runtime.cs/EvaluateCampaignTriggers()` replaces `Triggers` with `Where(...).ToList()` every timer evaluation. Remove triggered entries in place after evaluating the current list.
25. **PERF-025 — ResetLevel allocates a ship snapshot array every episode.** `Scripts/Levels/Level.Reset.cs/ResetLevel()` calls `State.GetShips().ToArray()` because killing mutates the state list. Reuse a dedicated ship snapshot list/buffer while preserving the pre-kill membership snapshot.
