# Performance Ledger

Static-only audit; no runtime measurements are claimed. This ledger contains unresolved validated optimization opportunities only.

1. **PERF-004 — Linear ship-damage reservation lookup.** `Scripts/Levels/GameState.Queries.cs/GetShipDamageStatus()` scans a growing list on repeated combat/targeting paths. Maintain an ID-keyed index while preserving existing status object identity/list semantics and cleanup.
2. **PERF-005 — Static Pathfinder grid recopied by physics frame.** `Scripts/Levels/Pathfinder.Obstacles.cs/UpdateDynamicObstacleLayer()` copies the full base-clearance grid again in static-only mode even when no dynamic obstacle changed it. Refresh only after static dirtiness or a dynamic→static transition.
3. **PERF-006 — Standing-request list allocated every rendered frame.** `Scripts/Server/Socket.cs/CheckStandingRequests()` calls `StandingRequests.ToList()` unconditionally. Early-return when empty and reuse a mutation-safe snapshot list.
4. **PERF-008 — Socket response envelope parsed twice.** `SocketResponseLifecycleGuard.ShouldSuppressResponse()` and `Socket.Message()` independently decode/deserialize the same response. Parse once and pass the envelope through suppression/dispatch while preserving error ordering.
5. **PERF-009 — Closest/furthest weapon sorts recompute geometry keys.** `Weapon.MakeSortedTargetingList()` calls `DistanceTo()` repeatedly from sort comparators. Cache each candidate distance once per sort.
6. **PERF-010 — Rocket flare SetActive no-ops every physics tick.** `Scripts/Entities/Ships/Ship.Visuals.cs/SetRocketFlares()` repeats identical activation calls. Guard each requested state with `activeSelf`.
7. **PERF-014 — Mouse-edge pixel threshold projected four times per frame.** `Scripts/Levels/LevelInputManager.cs/CheckInputs()` repeats the same world-to-screen conversion; compute it once per invocation.
8. **PERF-015 — Custom-sprite pixel matching performs unnecessary square roots.** `Scripts/Utilities.cs/GetChangablePixelsForImage()` calls `Vector3.Distance()` for every color×pixel test. Compare squared RGB distance to a squared threshold and precompute source color values.
9. **PERF-016 — ColorPicker allocates and sorts the whole palette to find one nearest color.** `Scripts/UI Components/ColorPicker.cs/SetColor()` creates dynamic objects, computes distances, sorts them, then takes the first. Use one best-candidate scan with squared RGBA distance and stable first-tie behavior.
10. **PERF-017 — ColorPicker repeatedly resolves stable UI components.** Cache the color-square `Image`, hex `TMP_InputField`, and color-sheet `RectTransform` instead of repeated `GetComponent` calls during pointer/input work.
11. **PERF-019 — Matchup strategy selection fully sorts for one winner.** `Scripts/Levels/Commands/MatchupStrategy.cs/SortSquads()` sorts for scalar min/max cases; closest/furthest also recompute distance keys and ship-type strategies recount ships inside comparators. Use single-pass extrema where tie semantics permit and precompute keys where existing `List.Sort` semantics must remain.
12. **PERF-020 — Full command targeting sorts recompute closest/furthest keys.** `Scripts/Levels/Commands/Command.cs/MakeTargetingQueue()` needs the full order but can cache each ship's squad-distance once before sorting.
13. **PERF-021 — Reset teardown allocates empty/snapshot arrays unnecessarily.** `Scripts/Levels/GameState.Registry.cs` creates `ToList`/`ToArray`/LINQ release snapshots even when runtime/release collections are empty. Add empty fast paths and reuse mutation-safe buffers.
14. **PERF-022 — GameState episode reset recreates core containers.** `Scripts/Levels/GameState.cs/ResetState()` allocates new spotted lists, numeric arrays, Hive Mind dictionaries, and vision sets each reset. Clear/reuse containers while preserving pooled-ship teardown semantics.
15. **PERF-023 — Automated setup/reset emits unconditional formatted logs.** `Scripts/Levels/Level.Reset.cs/SetupLevel()` contains routine `Debug.Log` calls reached by repeated training setup. Gate nonessential diagnostics on automated training paths.
16. **PERF-025 — ResetLevel allocates a ship snapshot array every episode.** `Scripts/Levels/Level.Reset.cs/ResetLevel()` calls `State.GetShips().ToArray()` because killing mutates state. Reuse a dedicated snapshot list/buffer while preserving pre-kill membership.
17. **PERF-026 — SaveAndEnd allocates multiple teardown snapshots.** `Scripts/Levels/Level.Ending.cs/SaveAndEnd()` creates arrays/lists for ships, fog visions, markers, obstacles, and projectiles before mutation. Reuse dedicated mutation-safe teardown buffers.
18. **PERF-027 — Aggressive pursuit allocates a LINQ ship array each coroutine run.** `Scripts/Levels/Commands/Aggressive.cs/MoveTowardsEnemiesAcrossFrames()` uses `Where(...).ToArray()` although only one pursuit coroutine may run at a time. Reuse a filtered ship snapshot list.
19. **PERF-028 — Hive Mind request ban sets are rebuilt with LINQ each decision.** `Scripts/Levels/Squad.Commands.cs` recreates ship-type and command-type sets on request paths. Refill instance-owned sets without changing request-local availability semantics.
20. **PERF-029 — The capped squad ship list is rebuilt multiple times for one matchup.** `Squad.MakeMatchupAndGetCommand()` calls `GetShipsForMatchup()` repeatedly for encoding and friendly-health calculation. Build the capped snapshot once per request and reuse it.
21. **PERF-030 — Matchup encoding allocates a character array through LINQ every call.** `Squad.AddToMatchup()` selects ship letters into a new array before sorting. Reuse a bounded character buffer and sort only the populated range.
22. **PERF-031 — Heal command rebuilds recurring collections.** `Scripts/Levels/Commands/Heal.cs` rebuilds filtered beehive lists/queues and a `Distinct().ToList()` visual set on recurring timers. Prune/refill existing collections and reuse a beehive set while preserving healing reservations.
